# School Friendship Network

[![Python 3.14.7](https://img.shields.io/badge/-Python_3.14.2-a8902b?style=for-the-badge&logo=python&logoColor=white)](https://www.python.org/) ![Code licence](https://img.shields.io/badge/🛡_Licence-MIT-8a00c2?style=for-the-badge&labelColor=gray) [![ORCID](https://img.shields.io/badge/ORCID_Thomas_Slater-0009--0007--0838--7499-A6CE39?style=for-the-badge&logo=orcid&logoColor=white)](https://orcid.org/0009-0007-0838-7499)

Implementation of the School Friendship Network (SFN) random graph using Python and NetworkX is demonstrated. For further information about SFN see the original article [here](https://doi.org/10.1371/journal.pone.0055371).

> Huerta-Quintanilla R, Canto-Lugo E, Viga-de Alva D (2013) Modeling Social Network Topologies in Elementary Schools. PLOS ONE 8(2): e55371. <https://doi.org/10.1371/journal.pone.0055371>
